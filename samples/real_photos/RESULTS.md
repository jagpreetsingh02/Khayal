# Reader accuracy: real photos vs synthetic

No real photos have been measured yet. Every accuracy number in this repository so far comes
from synthetic images (drawn by a script or generated by an image model), which are much
easier to read than a phone photo of a real meter.

To measure: add photos (see README.md in this folder), then run from `backend/`:

```bash
uv run python ../scripts/accuracy_test.py --reader groq --yes --pace 21
```

This file is then rewritten with the real and synthetic results side by side.
